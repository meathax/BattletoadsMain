# Battletoads core for MiSTer

Source code for the Battletoads (Rare, 1994) arcade core for MiSTer (DE10-Nano, Quartus 17.0).

- `rtl/` - core logic (TMS34020 GSP, TMS320C1X, T80, video/DDR/SDRAM, platform glue)
- `sys/` - MiSTer framework
- `src/` - CPU-side assembly sources
- `Arcade-Battletoads.qpf/.qsf/.sdc`, `files.qip` - Quartus project
